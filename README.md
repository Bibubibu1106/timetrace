# 时光待办 · TimeTrace Todo

> 一款专注于**「精确记录创建日期、完成日期与时隔跨度」**的多端待办与心愿清单应用。采用**时光银河 (Time Galaxy)** 星空磨砂玻璃设计，支持 **Android 独立 APK + iPhone / iPad / 桌面端 PWA** 多端无冲突云同步。

- 🌐 **在线访问 / 添加到主屏幕 (PWA)**：[https://bibubibu1106.github.io/timetrace/](https://bibubibu1106.github.io/timetrace/)
- 📱 **安卓独立安装包**：仓库根目录 [`时光待办.apk`](./时光待办.apk)

---

## ✨ 核心特性

1. **双时间戳与「时隔」记录**
   - 新建事项自动记录精确到分的**创建时间**（点开详情可看精确到秒的完整记录，支持微调补录）。
   - 完成事项自动记录**完成时间**，并以无压力的**「时隔 XX」**（如 `时隔 12天`、`时隔 2小时`）呈现从记下到达成的时间跨度；未完成的长期事项温和显示 `已记下 X天`。
2. **默认长期有效 + 可选 DDL 截止日**
   - 随手记下的电影、种草、灵感默认**长期有效**；需要卡死时间节点的任务可手动指定 **DDL 截止日期**，自动置顶并显示剩余/超期天数。
3. **双向渐进滑动手势**
   - **按住向右拉**：轻拉提示 `继续右拉完成`，继续右拉到底松手即可快捷打卡完成（或恢复待办）。
   - **按住向左拉**：轻拉提示 `继续左拉删除`，继续左拉到底松手即可快捷删除事项。
4. **整版可视化滑动月历与时间轴**
   - 支持左右滑动切换月份，日历格子底部以三色圆点直观标记：**橙点（有待办 DDL）**、**紫点（有新建）**、**绿点（有完成）**，点击任意日期即可回溯当天记录。
5. **高区分度撞色分类标签**
   - 内置 8 色高对比圆点调色盘，支持自定义新增分类或点击已有标签直接切换圆点颜色。
6. **免服务器多端云同步（Gitee 私有代码片段）**
   - 采用基于 `updatedAt` / `deletedAt` 的条目级增量合并算法（LWW），多台设备同时增删改也不会互相覆盖丢失。
   - 支持 **`TT1-` 跨设备极速配对码**，绑定一次永久记忆，打开应用或修改事项后自动静默同步。

## 🚀 多端安装与同步指南

### 1. 各端安装方式
- **Android 手机**：下载本仓库中的 [`时光待办.apk`](./时光待办.apk) 直接安装。
- **iPhone / iPad**：使用 **Safari** 打开 [`https://bibubibu1106.github.io/timetrace/`](https://bibubibu1106.github.io/timetrace/) → 点击底部分享按钮 → 选择 **「添加到主屏幕」**，即可生成高清桌面图标并全屏离线运行。
- **Mac / Windows 电脑**：浏览器直接打开上述网址，或点击地址栏右侧「安装应用 / 添加到程序坞」。

### 2. 码云 Gitee 同步配置（只需配置一次）
1. 登录 [码云 Gitee 私人令牌页](https://gitee.com/profile/personal_access_tokens) → 生成新令牌 → 仅勾选 **`gists`** 权限并提交复制。
2. 在首台设备打开「时光待办」→ **「我的」** → **「多端云同步」**，粘贴令牌并点击 **「首台设备：一键创建同步库」**。
3. 点击 **「生成并复制本机配对码」**，将生成的 `TT1-` 开头配对码发送到其他设备，点击 **「粘贴配对码一键绑定」** 即可永久互通。

```text
├── index.html              # Web / PWA 主程序入口（内联完整样式、逻辑与星空背景，兼容 GitHub Pages）
├── manifest.json           # PWA 桌面安装清单
├── sw.js                   # Service Worker 离线缓存与网络优先更新脚本
├── icon.svg                # 矢量应用图标
├── icon-192.png            # PWA 标准图标
├── apple-touch-icon.png    # iOS 主屏幕高清图标 (180x180)
├── 时光待办.apk             # Android 原生签名独立安装包
├── src/                    # 模块化前端源码与构建脚本
│   ├── template.html       # 页面结构模板
│   ├── styles.css          # 响应式样式表（手机 / iPad 侧边栏 / 电脑双列自适应）
│   ├── store.js            # 本地存储、时间戳格式化与默认数据模块
│   ├── sync.js             # Gitee Gist / 私有云增量合并同步引擎
│   ├── app.js              # 交互控制器、滑动月历与双向滑动手势
│   ├── galaxy_art.py       # 时光银河矢量星空背景与图标生成器
│   └── bundle.py           # 单文件内联打包脚本
├── android-apk-project/    # Android WebView 全屏沉浸式原生包装工程
├── build_apk.sh            # Android 独立 APK 编译签名脚本
└── server/
    └── timetrace_sync_server.py  # 可选：零依赖 Python 私有云同步服务端
```
